# 使用指南

## 一、导出

1. 打开 PCB 文档 → 顶部菜单「规则配置」→「导出设计规则配置…」。
2. 勾选要包含的模块（六个模块默认全选，勾选会被记住，下次自动沿用）。
3. 填写输出文件名 → 「开始导出」，浏览器会下载一个 JSON 文件。

导出只读取当前 PCB，不会修改任何规则。

导出弹窗中还可以：

- 查看「这份文件将包含」清单：按勾选模块实时列出网络类名单、网络规则 / 网络-网络规则（按分组）、差分对、等长网络组数量。
- 使用「附加网络集合规则」：直接粘贴两个网络集合（`/` 或空格分隔，忽略大小写），选择分组与规则后「添加到导出」。这些集合**不校验当前 PCB 是否存在对应网络**，会原样写入配置文件；导入时与目标 PCB 的实际网络求交后展开为两两网络-网络规则，没有的网络自动跳过并在日志汇总。也支持只填一个集合。适合把团队完整的规则沉淀成一份模板文件。
- 网络类名称与集合一一对应（各填一个，可选）：填了类名的一侧，导入时网络加入新建 / 同名已有网络类；两侧都有类名且无冲突时，网络对精简为一条「类A ↔ 类B」。也支持只填一个集合——填类名仅建类，不填类名则作为「网络规则」条目写入文件。导入只处理目标板上实际存在的网络。
- 网络类名称与集合一一对应（集合A、集合B 各一个，可选）：填了类名的一侧，导入时网络加入新建 / 同名已有网络类；两侧都有类名且无冲突时，网络对精简为一条「类A ↔ 类B」。也支持只填一个集合——填类名仅建类，不填类名则作为「网络规则」条目写入文件。导入只处理目标板上实际存在的网络。
- 可选填「网络类名称」：导入时把两个集合的网络全部加入这个新建网络类，网络对精简为一条「类 ↔ 类」。若目标板上有任一网络已属于其他网络类，则不建类、改为逐条展开并在日志提示（已属于同名类不算冲突）。

导出文件形如：

```json
{
  "schema": "easyeda-eda-rule-config-set",
  "schemaVersion": 1,
  "generator": { "name": "rule-configuration-management", "version": "1.1.1" },
  "edaVersion": "3.2.196",
  "exportedAt": "2026-09-30T04:00:00.000Z",
  "source": { "pcb": "PCB6", "unit": "mm", "ruleConfigName": "..." },
  "modules": ["ruleConfig", "netRules", "netByNetRules", "netClasses", "differentialPairs", "equalLengthGroups"],
  "data": { "ruleConfig": { "...": {} }, "netClasses": [{ "name": "DDR", "nets": ["D0", "D1"] }] }
}
```

## 二、导入

1. 打开目标 PCB → 「规则配置」→「导入设计规则配置…」。
2. **选择文件**：支持本扩展导出的配置集，也兼容嘉立创 EDA 内置「导出配置」的裸规则文件。
3. **预览差异**：统计新增 / 修改 / 删除 / 保留 / 跳过 / 不支持，可展开查看每条差异的字段级明细（本机值 → 目标值）。
4. **确认导入**：写入并复核，结果页给出每个模块的成功/失败与剩余差异。

### 匹配与作用域规则

- **作用域**：只处理配置文件里声明过的模块。文件没提到的模块一律不动（避免把「文件里没有」误判成「需要清空」）。
- **网络匹配**：按网络名匹配，**忽略大小写**；当前 PCB 不存在的网络会被跳过，并在日志里汇总告诉你是哪些。
- **差分对**：只要有一端网络缺失，**整对不导入**；其他模块（网络规则、网络类、等长网络组）只跳过缺失的那个网络。
- **网络类 / 差分对 / 等长网络组只增不删**：不删除当前 PCB 已有的类、对、组，只把当前 PCB 已有的网络移入已有类或新增类。本机独有、配置文件里没有的类 / 对 / 组原样保留，预览不再逐条提示。
- **数值容差**：内置固定 5e-5 mm（≈0.05 µm），用于吸收 mil/小数位换算误差；另有「12 位有效数字内相等」的浮点噪声保护。不再提供用户设置项。

### 网络集合与网络对规则

从 AD 迁移过来的团队习惯是「两个输入框搞定两两规则」。本扩展提供两条等价路径，写入时都会把集合**展开为具体网络对**（编辑器接口只保存具体网络对；引用不存在网络的条目会被编辑器静默丢弃，因此无法"先写入、生效时再判断"）：

**1. 顶部菜单「网络集合规则…」（推荐日常使用）**

1. 打开 PCB → 「规则配置」→「网络集合规则…」。
2. 选规则分组（如 `Safe Spacing`）。
3. 集合A、集合B 各贴一组网络名（`/`、`,`、`，`、`;`、空格均可，忽略大小写）。
4. 在「分配规则」里从所选分组的现有规则中选一个（显示的是规则键，如 `safeClearance1`）。**网络-网络规则的 `rule` 字段存的是规则键，编辑器解析不到就回落为默认规则**，所以这里只能选已存在的规则；分组还没有规则时，请先在「规则管理」中创建。
   小技巧：把规则命名为与表格一致的间距文字（如 `表层0.3，内层0.25mm`），客户表格的「间距」列就能直接对上。
5. 可选：为集合A / 集合B 各填一个「网络类名称」——填了类名的集合，其网络会加入新建（或同名已有）网络类；任一网络已属于其他网络类时，该侧回退为逐条网络对并在日志提示。两侧都填时，没填类名的一侧按具体网络逐条展开（「类 ↔ 网络」组合）。
6. 也可以只填一个集合：填类名仅创建网络类；不填类名则写入这些网络的网络规则分配。
7. 也可以点「导入表格（CSV）」批量添加。模板表头为 `setA,classA,setB,classB,rule`，大小写不敏感、列序随意；`classA` / `classB` 可留空，集合内网络用 `/` 分隔，一行表示一条集合规则。CSV 支持 UTF-8 和 GBK；表格里的规则必须属于当前所选分组。项目模板：`templates/附加网络间距模板.csv`。
8. 界面实时显示展开预览与缺失网络；点「展开并写入」。

写入是**追加**：只往所选分组加新条目（自动去重，已存在的对不重复加），不动其它分组与已有条目。写入后结果页给出明细与日志，并支持一键还原到写入前。

**2. 配置文件里写集合（用于团队共享完整模板）**

`netByNetRules` 条目的 `net1` / `net2` 可以是集合：

```jsonc
"Safe Spacing": [
  { "net1": { "type": "set", "name": "正极回路", "nets": ["B+", "B+1", "B+2"] },
    "net2": { "type": "set", "name": "负极回路", "nets": ["B-", "VSS", "GND"] },
    "rule": "表层0.3，内层0.25mm" }
]
```

导入时与当前 PCB 网络求交后按笛卡尔积展开（上例 = 9 条网络对）；文件保留集合原样，同一份文件可直接导入其他 PCB，缺哪些网络就跳过哪些并汇总进日志。也支持集合与具体网络、网络类混用。

**预览可读性**：集合展开出的网络对在「预览差异」里按来源合并展示——一行显示「分组 · 集合A（N 个网络） ↔ 集合B（M 个网络）」，备注里给出分配规则与展开对数，不必逐条翻看笛卡尔积。

注意：集合只在导入时求值。PCB 后续新增的网络不会自动获得规则，需要重新导入。

**规则键校验**：导入配置文件时，若引用的规则键在当前规则配置的对应分组中不存在（该分组有规则但键名对不上），相关条目会被跳过并在日志中提示「导入后会变成默认规则」——不会写入一堆不生效的规则。

### 一键还原

导入完成后，结果页会出现「**还原到导入前**」按钮：它把预览时抓取的现场当作配置再写回去，等价于撤销这次导入。

原理说明：平台没有开放规则配置的撤销栈（实测 `MSG_BUS_PCB.publish('undo')` 只回退画布图元，规则值不变），所以本扩展用「导入前快照 + 反向写入」实现回退。还原范围与本次导入的作用域一致；还原同样是一次写入，成功后会释放编辑器残留的进度遮罩。还原按钮只在本次会话有效，关闭窗口后快照即失效。

还原是**精确回滚**，与普通导入的「只增不删」策略不同：

- 本次导入新建的**网络类 / 差分对 / 等长网络组会被删除**；
- 导入时被迁移走的成员网络会被**加回原来的类 / 组**（网络只能属于一个网络类，导入把网络放进新类时，它会从原类移出；还原会把它放回去）；
- 还原结束后会做一次终检，管理器状态与导入前一致才判定成功。

真机实测：导入新增 3 个网络类 → 还原后 3 个类均被删除、被抢占的成员网络归位、终检通过、剩余差异 0。

## 三、常见提示与限制

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 导入后仍有「删除」项 | 规则分组 / 普通网络规则条目无法删除 | 平台限制，日志会逐条列出 |
| 还原后仍留有本机原有的规则分类 / 分组 | 顶层分类与规则分组由编辑器维护，接口不能增删 | 这类分组可以是空的，不影响规则值；网络类 / 差分对 / 等长网络组则会被精确还原 |
| 配置文件含当前版本没有的功能（如 V4 的 `Physics / Height`） | 本机默认就没有该分类/分组，无法新增 | 静默跳过，不影响其他条目 |
| 配置名变成「自定义配置N」 | 覆写规则配置后编辑器的正常行为 | 未点保存不会写入云端配置库；可在预览页勾选「不再提示」 |
| 导入后底部出现进度条并卡在 50% | 编辑器自身在写入后重建铺铜的已知问题（V4.1 已修复） | 扩展会在导入结束后自动释放该遮罩 |
| 同样的文件重复导入 | 幂等 | 第二次预览应显示「完全一致，无需写入」 |

## 四、设置项

| 设置键 | 默认值 | 说明 |
| --- | --- | --- |
| `lastExportModules` | 未记录 | 上次导出勾选的模块 |
| `uiLanguage` | `auto` | 界面语言，`auto` / `zh-Hans` / `en` |

## 五、多语言

界面与提示支持简体中文、英文。默认跟随编辑器语言（非中文一律按英文），也可通过设置项 `uiLanguage` 固定。

扩展内文案由 `locales/*.json` 提供，代码内置同名回退表，因此即使语言包加载异常也能正常显示。
